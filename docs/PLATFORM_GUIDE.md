# SOC Academy - Complete Platform Guide

## Welcome to SOC Academy

SOC Academy is a comprehensive, production-ready Security Operations Center training platform designed for cybersecurity professionals, analysts, and students.

---

## 🎓 Learning Paths

### Beginner Path (8-12 weeks)
**Goal**: Build foundational cybersecurity knowledge

1. **Linux Fundamentals** (3 weeks)
   - Command-line basics
   - File system navigation
   - User and permission management
   - Shell scripting introduction

2. **Networking Basics** (2 weeks)
   - OSI model
   - TCP/IP protocols
   - DNS and HTTP
   - Network tools (ping, traceroute, netstat)

3. **Log Analysis Introduction** (2 weeks)
   - Log types and formats
   - Log parsing techniques
   - Common log locations
   - Basic correlation

4. **SOC Fundamentals** (2 weeks)
   - SOC operations overview
   - Incident response basics
   - Alert triage
   - Escalation procedures

5. **Security Monitoring** (3 weeks)
   - Event sources
   - Monitoring strategy
   - Dashboard creation
   - Alert tuning

### Intermediate Path (10-14 weeks)
**Prerequisite**: Beginner Path  
**Goal**: Develop practical SOC analyst skills

1. **SIEM Essentials** (3 weeks)
   - Splunk basics
   - Wazuh fundamentals
   - ELK Stack introduction
   - Search and query language

2. **Log Correlation & Rules** (3 weeks)
   - Correlation concepts
   - Detection rule writing
   - Sigma rules
   - False positive reduction

3. **Web Attack Analysis** (2 weeks)
   - Web attack vectors
   - Apache/Nginx log analysis
   - WAF logs
   - SQL injection detection

4. **Threat Hunting** (3 weeks)
   - Threat hunting methodology
   - Advanced SIEM queries
   - MITRE ATT&CK mapping
   - IOC analysis

5. **Incident Response** (3 weeks)
   - IR workflow
   - Containment techniques
   - Evidence preservation
   - Post-incident analysis

### Advanced Path (12-16 weeks)
**Prerequisite**: Intermediate Path  
**Goal**: Master advanced SOC operations

1. **Malware Analysis** (4 weeks)
   - Static analysis
   - Dynamic analysis
   - Behavioral analysis
   - Sandbox usage

2. **Detection Engineering** (4 weeks)
   - Advanced rule development
   - Tuning and optimization
   - Sigma to detection conversion
   - Testing frameworks

3. **Threat Intelligence** (3 weeks)
   - IOC analysis
   - Threat feeds
   - STIX/TAXII
   - ATT&CK framework deep dive

4. **Advanced DFIR** (3 weeks)
   - Memory forensics
   - Disk forensics
   - Timeline analysis
   - Artifact analysis

5. **Cloud Security** (2 weeks)
   - Cloud monitoring
   - Identity and access
   - Data protection
   - Compliance
